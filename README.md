# omnisense/omnical

**Reserved, not released yet.**

Read and write a calendar, and know the public holidays, under any PHP host: one contract by capability, one package per provider, as every
family of the [Omni ecosystem](https://glitchr-omnisense.github.io/omnisense/). Its first
providers: Google Calendar, Microsoft Graph calendar, CalDAV, OpenHolidays API, Nager.Date.

The name is kept so that the family is built here, once. To write or maintain one of its
providers, see the site's [contribute page](https://glitchr-omnisense.github.io/omnisense/contribute)
and open a "Provider" issue there.
